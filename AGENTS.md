# Grok Test Session

Browser lookdev for one original werewolf in a small mythic court. Three.js WebGPU, TypeScript, Vite.

## Build Commands

- Typecheck: `npm run typecheck`
- Test: `npm test`
- Build: `npm run build`
- Dev server: `npm run dev`

There is no ESLint script. Do not invent one.
